# 数据源登录状态（历史记录）

> 本文件是 2026-07-05 调研快照，只保留观察结果，不是当前执行契约。
> 运行前必须以主技能的 v1.17.0 来源、安装、启动和持久化门禁为准。

## 历史观察

| 数据源 | 当时的观察 | 现行处理 |
| --- | --- | --- |
| 知乎 | 部分问答无需登录，评论可能需要认证 | 先免登录；需要时由用户在可见窗口登录。 |
| 小红书 | 常见登录墙，需要扫码或手机号 | 用户在可见窗口完成认证，Agent 不处理凭据。 |
| Reddit | 页面访问可能触发机器人检测 | 记录缺口，使用 Hermes `web_search` 查找公开替代信息。 |
| X/Twitter | 登录流程可能多次跳转 | 以当前 snapshot 的 URL 和 ref 为准。 |
| 知识星球 | 可能要求手机扫码 | 等待用户在窗口完成扫码。 |
| 少数派 | 直接登录 URL 可能跳转到错误页 | 从首页开始，以当前页面状态决定下一步。 |

## 现行登录原则

- 账号、密码、二维码、短信、2FA 和验证码只由用户在可见窗口输入。
- 不用历史账号状态推断当前授权；使用前重新确认页面和 `userId`。
- 页面访问失败时如实记录目标 URL、时间和错误，再使用 `web_search` 回退。
- 历史 cookie 数量、登录账号和旧页面结论不构成当前操作说明。
