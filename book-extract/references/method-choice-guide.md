# 用户自行判断：MinerU 还是视觉？

Agent **只提供本参考、直接请你选择**；**不**试跑 PDF、**不**替你看文件下结论、**不**说「建议你用某某」。

## 直接选择

请回复 **A（MinerU）** 或 **B（视觉大模型）**。不确定时，可对照下面自行判断。

## 你怎么判断（自问即可）

| 你更在意… | 可优先考虑 |
|-----------|------------|
| 免费、本地跑、长书不怕慢 | **A MinerU** |
| 大量 **K 线/截图/复杂版式/手写**，要「读懂图」 | **B 视觉** |
| **表格、公式** 要结构化 Markdown | **A MinerU** 往往够用；图多仍可坚持选 B |
| 已是 **电子版**、以可复制文字为主 | **A MinerU** 常够用；你也可选 B |
| 想走 **本地千问 / Agent 读图 / 云端 API** | **B 视觉**（再选 `agent_native` 或 `external_api`） |

## 常见误区

- **「扫描件」** — 两种都能试；选哪种由你定，Agent 不预判。
- **「MinerU 能转就行」** — 即使 MinerU 能转，你仍可选视觉（例如要更好的图注理解）。
- **「让 AI 先看几页再推荐」** — 本流程**不支持**；请你自己看 PDF 特点后回复 A/B。

## 视觉子模式（仅选 B 或拍照时）

| 选项 | 适合你如果… |
|------|-------------|
| **agent_native** | 当前对话的 AI 能直接读图，不想配 API |
| **external_api** | 要批量离线、本地千问（LM Studio）、或指定云端模型 |

请回复 **1（agent_native）** 或 **2（external_api）**。
