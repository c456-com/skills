# Short Viral Content — 短视频爆款内容引擎

> **一句话**：给定一段内容的核心思想+受众画像，自动在小红书/抖音/微信视频号发掘高热关键词，输出 10+ 候选标题和平台特化推荐。

## 输入

| 字段 | 说明 | 示例 |
|------|------|------|
| **中心思想** | 这段视频要传递的核心信息 | "AI 时代的产品经理如何不被淘汰" |
| **受众人群** | 目标用户画像 | 25-35 岁互联网从业者，产品经理、创业者 |
| **人群偏好** | 痛点/兴趣/内容消费习惯 | 焦虑职业发展、关注 AI 趋势、喜欢真实案例 |
| **平台** | 目标分发平台（默认全选） | 小红书 / 抖音 / 微信视频号 |

## 工作流

### Step 1: 种子词生成

从中心思想提取 3-5 个核心种子词，中英文各一组。用 product-niche-discovery 的「五维扩展矩阵」扩展为搜索串：

| 维度 | 模板 |
|------|------|
| 疑问/求助 | 中心思想 + "怎么" + "如何" + "是什么" |
| 吐槽/负面 | "别再" + "避坑" + "后悔" + "上当" |
| 对比/评测 | "实测" + "对比" + "VS" + "选哪个" |
| 场景+人群 | "打工人" + "学生党" + "宝妈" + "创业者" |
| 数字公式 | "3个" + "5步" + "10个" + "1分钟" |

### Step 2: 平台关键词发掘

针对每个平台搜索，收集以下数据：

**小红书：**
```
site:xiaohongshu.com <关键词> 标题 赞
```
- 热门笔记标题模式
- 高互动标题的结构特征（数字/情绪词/悬念）
- 关联话题标签（#XXX）
- 评论区高频词

**抖音：**
```
site:douyin.com <关键词> 热门
```
- 热门话题挑战
- 高播放量视频标题
- 搜索联想词

**微信视频号：**
```
site:weixin.qq.com <关键词>
```
- 热门内容标题
- 朋友圈分享标题特征

### Step 3: 热度评估

对每个候选关键词评估：

| 维度 | 评估方法 |
|------|---------|
| 搜索热度 | 微信指数/百度指数趋势 |
| 竞争程度 | 搜索结果数量 + 头部内容互动量 |
| 时效性 | 近 1 个月讨论是否在增长 |
| 目标匹配度 | 是否与受众人群和偏好一致 |

### Step 4: 标题生成

每个平台输出 3-5 个候选标题，遵循以下公式：

**小红书风格：** 情绪钩子 + 数字/结果 + 人群标签 + 解决方案
- 示例：「00后用了这个AI工具，3个月从专员到主管🔥」
- 示例：「别再盲目学产品了！AI时代的产品经理必备3大技能」

**抖音风格：** 强悬念/反常识 + 限时感 + 可视化承诺
- 示例：「月薪3k到3w，我只做对了一件事…」
- 示例：「90%的产品经理都不知道这个AI工具」

**微信视频号风格：** 价值前置 + 身份认同 + 信任感
- 示例：「做产品10年，这是我见过最实用的AI工作流」
- 示例：「给产品经理的AI生存指南：不会用AI的人正在被淘汰」

### Step 5: 描述+标签输出

每个标题附带：
- 📝 视频简介（3 句话以内）
- 🏷️ 话题标签（5-10 个，分平台特化）
- 🎬 黄金 3 秒开头句

## 标题公式库

### 情绪驱动型
```
[情绪词] + [人群] + [结果]
「震惊！打工人用AI一周干完了一个月的活」
「后悔没早点知道的5个AI工具」
```

### 反常识型
```
我劝你[别做某事] + [理由]
「我劝你别学产品经理，除非…」
「别再花钱买XX了，免费替代品更好用」
```

### 结果承诺型
```
[数字]步/[方法]，[时间]内[结果]
「3步搭建个人知识库，1小时搞定」
「每天10分钟，30天变身AI高手」
```

### 身份认同型
```
[人群标签] + [真实场景] + [解决方案]
「打工人必备：每天省下2小时的工作流」
「这款工具，产品经理用了都说好」
```

## 输出格式

```yaml
platform: 小红书/抖音/微信视频号
keywords:
  - word: "AI产品经理"
    heat: 高
    competition: 中
    trend: "↑ 上升"
titles:
  - title: "候选标题1"
    hook: "黄金3秒开场句"
    description: "视频简介文案"
    tags: ["#AI", "#产品经理", "#职场"]
    expected_csat: "高互动潜力（情绪钩子+身份认同）"
```

## 验证原则

- 每个标题必须通过「3 秒停滑测试」——前 5 个字必须有钩子
- 关键词选择「搜索量×目标匹配度」最高 TOP 10
- 跨平台标题必须差异化，不复制粘贴
- 避免敏感词和平台违禁词
- 标签不超过 10 个，小红书优先长尾标签
