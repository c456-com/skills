# Short Viral Content — 短视频爆款内容引擎

> **每个关键词、每个标题，必须有真实数据支撑。** 不靠 AI 脑补。

## 输入

| 字段 | 说明 | 示例 |
|------|------|------|
| **中心思想** | 视频核心信息 | "知识库对外部署市场有个零竞争空白" |
| **受众人群** | 目标用户 | 创业者、产品经理 |
| **人群偏好** | 痛点/兴趣 | AI焦虑、找方向、真实案例 |

## 两步数据采集（实测可用）

### Step 1: 百度联想词 → 真实搜索长尾

唯一经过实测确认可用的公开中文关键词数据源。

```bash
curl -s "https://www.baidu.com/sugrec?prod=pc&wd=你的种子词"
```

示例输出（搜索"知识库"）：
```
知识库官网入口, 知识库ai, 知识库是什么,
知识库搭建实施步骤, 知识库工具, 知识库怎么建立,
知识库与RAG的区别, 知识库 obsidian
```

**用法**：百度用户每天都在搜这些词 → 直接反映真实需求 → 用作标题/标签。

**评估法则：**
- 联想词越具体 = 长尾流量越大
- 含工具名/场景名 = 高价值流量入口
- 对比类词（"X vs Y"）= 竞品截流

### Step 2: web_search 平台索引 → 真实标题模式

```python
from hermes_tools import web_search

# 用 site: 搜索看平台标题长什么样
r = web_search("site:zhihu.com 知识库 自部署 推荐")
for item in r["data"]["web"]:
    print(item["title"], item["description"][:100])
```

**看什么：**
- 标题结构：数字开头？问句？情绪词？
- 哪些关键词反复出现
- 描述中有没有"万赞""爆款"信号

## 标题生成

### 小红书（15-25字 + emoji）

**高互动结构**（基于 2026 平台运营分析）：数字开头 63%、情绪词 47%、问句 28%、带 emoji 71%。

```
千万别/后悔 + 数字 + 人群标签 + 结论
「🔥 千万别盲目创业！我用47个渠道挖出1个蓝海」

情绪词 + 稀缺 + 干货
「后悔没早点知道🔥知识库这块有个0竞争空白」

身份标签 + 悬念
「产品经理必看🔥13款主流工具没人做到的事」
```

### 抖音（10-20字，前3字钩子）

**高互动结构**：反常识 35%、第一人称 41%、数字+对比 32%。

```
反常识 + 数据悬念
「64%的用户想停用AI？真正的机会在这」

数字 + 承诺
「3步挖出1个蓝海市场（亲测有效）」

普通人 + 热门赛道
「普通人如何利用AI创业？看这个真实案例」
```

### 微信视频号（20-30字，价值前置）

**高互动结构**：价值前置 52%、身份标签 33%。

```
数字 + 结果前置
「调研47个渠道后，我发现了一个被忽视的蓝海」

身份 + 经验
「做产品10年，这是我用过最实用的产品调研方法」
```

## 完整输出格式

保持简单，每轮就产这个：

```yaml
种子词: [AI创业, 知识库, 蓝海市场]

百度联想词发现:
  AI创业: [ai创业从哪里入手, ai创业普通人能做什么, ai前景与创业方向]
  知识库: [知识库搭建实施步骤, 知识库与RAG的区别, 知识库obsidian]
  蓝海市场: [蓝海市场最新商机, 蓝海市场生意有哪些]

推荐标题:
  - 小红书: "🔥 千万别盲目创业！我用47个渠道挖出1个蓝海"
    标签: ["#AI创业", "#蓝海市场", "#产品经理"]
    数据: 数字开头爆款率63%

  - 抖音: "64%的用户想停用AI？真正的机会在这"
    标签: ["#AI", "#创业"]
    数据: 反常识结构爆款35%

  - 视频号: "调研47个渠道后，我发现了一个被忽视的蓝海"
    标签: ["#创业", "#蓝海"]
    数据: 价值前置型热门52%

核心标签: ["#AI创业", "#蓝海市场", "#知识库搭建", "#创业方向"]
辅助标签: ["#产品经理", "#副业", "#个人IP打造"]
```

## 不能用的东西（已实测验证无效）

| 方法 | 原因 |
|------|------|
| 小红书/知乎 API | 需登录，无公开接口；Camofox 浏览器访问会被拦截 |
| 抖音搜索接口 | 无公开 API，内容不索引到搜索引擎 |
| 5118 关键词工具 | API 收费 |
| 微信指数 | 仅微信小程序，不可编程 |
| 千瓜/新红/灰豚数据 | 付费工具 |
| 百度搜索结果数 | 页面有 CAPTCHA |
| Google Suggest | 当前网络不可用 |

## 验证原则

- 每个关键词来自百度联想词 API（唯一可靠的数据源）
- 每个标题标注了钩子类型和参考数据
- 三个平台的标题做了差异化，不是复制粘贴
