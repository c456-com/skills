# 标题公式库

> 三大平台通用的高互动标题结构，基于小红书/抖音/微信视频号 2026 年热门内容分析。

## 通用钩子类型

### 1. 数字公式
```
[N个] + [方法/工具/技巧] + [结果]
```
- 例子：「3步搭建个人知识库，1小时搞定」
- 例子：「5个让你效率翻倍的AI工具」

### 2. 反常识/反转
```
[常识否定] + [意外结论]
```
- 例子：「我劝你别再用Notion了」
- 例子：「64%的用户希望企业停止使用AI客服——但问题不在AI」

### 3. 身份代入
```
[人群标签] + [场景] + [痛点/解决方案]
```
- 例子：「产品经理的AI生存指南」
- 例子：「打工人必备：每天省下2小时的工作流」

### 4. 悬念钩子
```
[限时/限制] + [不完整信息] + [好奇心驱动]
```
- 例子：「我用这个工具做了3个月，结果…」
- 例子：「90%的人不知道的知识库秘密」

## 小红书特化

| 类型 | 公式 | 例子 |
|------|------|------|
| 情绪共鸣 | [情绪词] + [我] + [经历] | 「后悔没早点知道的5个AI工具🔥」 |
| 干货清单 | [数字] + [名词] + 合集 | 「私藏！6款免费知识库工具大合集」 |
| 避坑测评 | 别再 + [错误做法] + [真实代价] | 「别再盲目自建知识库了，血泪教训」 |
| 身份标签 | [人群] + 必备/必看 + [主题] | 「创业小白必看：找方向的最快方法」 |

**小红书标题特征：**
- 情绪前置：🔥/😭/💥 等 emoji 开头
- 字数 15-25 最佳
- 关键词前置（前 5 个字含核心搜索词）
- 标签 3-5 个，置顶标签含核心关键词

## 抖音特化

| 类型 | 公式 | 例子 |
|------|------|------|
| 强冲突 | [对立双方] + [结果反差] | 「产品经理 vs AI，谁会先被淘汰？」 |
| 知识差 | 你不知道的 + [反常识事实] | 「你不知道的3个知识库秘密」 |
| 限时焦虑 | [时间] + 不[行动] + [损失] | 「2026年了，还不学AI你就晚了」 |
| 互动引导 | [测试/挑战] + @用户 | 「测测你的产品思维能得几分」 |

**抖音标题特征：**
- 前 3 个字必须是钩子
- 字幕配合：黄金 3 秒口播开头
- 封面文字要大、少、对比强
- 悬念 > 信息量

## 微信视频号特化

| 类型 | 公式 | 例子 |
|------|------|------|
| 价值前置 | [实用价值] + [方法] | 「做产品10年，我总结了这套AI工作流」 |
| 身份共鸣 | [职业] + [真实故事] | 「一个产品经理的AI自救之路」 |
| 信任背书 | [经验] + [数据/结果] | 「调研47个渠道后，我发现了这个蓝海」 |
| 朋友圈友好 | 亲测 + [结果] + [推荐] | 「亲测！这个工具让我效率翻倍」 |

**视频号标题特征：**
- 更偏长标题（20-30 字）
- 朋友圈分享友好
- 信任感 > 悬念感
- 适合「朋友推荐」式口吻
