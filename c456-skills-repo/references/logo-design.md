# Logo Design Reference — c456-com/skills

## Derived from

Brand style from [c456-com/hermes-docker](https://github.com/c456-com/hermes-docker):
- Dark navy background (`#0a1628` → `#0f1f3a`)
- Glowing cyan accent (`#22d3ee` → `#06b6d4`)
- White bold text, gray thin subtitle
- Subtle grid pattern overlay

## Icon Concept

**Interlocking hexagons** — representing modules/nodes in a skill registry:

- Hex 1 (top-left, main): full opacity, thickest stroke → primary entry point
- Hex 2 (right, overlapping): 0.9 opacity → adjacent/connected skill
- Hex 3 (bottom-left): 0.7 opacity → underlying foundation/plugin
- Connection dots between hex centers → data flow / dependency links

Alternative concepts not used:
- Puzzle pieces (too literal)
- Stacked blocks (too generic)
- Gear/cogs (engineering feel, not "marketplace")
