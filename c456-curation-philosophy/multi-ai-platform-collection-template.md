# 多 AI 平台调研 —— 结构化采集模板

## 单平台记录模板

```markdown
# [平台名称]

- **测试时间**：YYYY-MM-DDTHH:MM
- **问题**：
- **登录状态**：无需登录 / 手机号 / 微信扫码 / 其他
- **联网搜索状态**：开启 / 关闭 / 未说明

---

## 答案原文

[完整复制 AI 的回答文本]

---

## 引用来源列表

- URL1（标题/说明）
- URL2（标题/说明）
...

---

## 行为观察

- **回答速度**：快 / 中 / 慢
- **引用格式**：角标 / 卡片 / 列表 / 底部来源区域 / 无显式引用
- **追问建议**：末尾是否主动提供后续方向
- **其他特征**：
  - 语气（中性/偏助手/偏销售）
  - 结构（有/无目录/表格/流程图）
  - 是否有商业话术或过度承诺
  - 是否分平台/分场景分析
  - 是否提供具体数据或案例
- **总体倾向**：一句话概括该平台的核心立场
```

## 行为观察速查表

| 观察项 | 判断标准 |
|--------|---------|
| 回答速度 | 快（<3秒）/ 中（3-10秒）/ 慢（>10秒） |
| 引用格式 | 角标上标（如¹²³）、卡片式（独立引用块）、底部来源列表、无引用 |
| 商业话术 | 自夸、过度承诺、推广自家产品、使用营销用语 |
| 结构完整度 | 有目录/表格/流程图 vs 纯文字段落 |
| 信息密度 | 每条事实有具体数据/来源 vs 模糊表述 |
| 追问倾向 | 末尾主动提供下一步方向 |
| 生态自推 | 平台是否推荐自家的产品/生态（豆包→字节、元宝→微信等） |
